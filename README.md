## 📖 About The Project

This is my personal **3D developer portfolio**, designed and developed to showcase my skills, projects, education, achievements, certifications, resume, and professional journey as an Information Technology student and developer.

Instead of creating a traditional portfolio website, I wanted to build an interactive and immersive experience by combining **3D graphics, modern UI design, smooth animations, responsive layouts, and interactive components**.

The portfolio also includes a functional contact form powered by **EmailJS**, allowing visitors to send messages directly.
